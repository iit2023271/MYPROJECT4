# BMI Calculator

Enter your height (cm) and weight (kg) and get your Body Mass Index plus your weight category.


## Features

- BMI calculation from height (cm) and weight (kg)
- Weight categories: **Underweight** (< 18.5), **Normal weight** (18.5 – 24.9), **Overweight** (≥ 25)
- Input validation with a friendly message for invalid values
- BMI categories reference table on the page

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

Just open `index.html` in any browser. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000
```
